## Starting point

Tick what you can already do without looking it up. Be honest; this decides where to start.

- [ ] Use `cd`, `ls`, `cat`, `less`, `grep`, `find` comfortably
- [ ] Explain `rwxr-x---` and what `chmod 640` does
- [ ] Install a package and start a service with `dnf` and `systemctl`
- [ ] Partition a disk, make a filesystem, and add it to `/etc/fstab`
- [ ] Read a service's logs with `journalctl`
- [ ] Explain the difference between an IP address, a port, and a hostname
- [ ] Say what DNS does and what an A record is
- [ ] Use `git add`, `commit`, and `push`
- [ ] Write a small Bash script with a loop and an `if`
- [ ] Set up SSH key login
- [ ] Explain what a certificate is and what a CA does

Fewer than 4 ticks: start at module 00 and do everything in order. 4-7: do 00, then use the check questions in 01 and 02 to decide what to skip. 8-11: do 00, skim 01-03, and start the real work at 04.
